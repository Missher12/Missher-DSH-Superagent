## 1.9.11 自动续作与来源规则（2026-11-12）

- 团队规划、成员执行和最终复核在没有问题、权限阻挡或运行中的会话时自动续作。最终汇总缺少交付记录也会在原协调会话补齐；手动停止的任务不自动恢复，真实问题和失败保留原因。每个交付周期最多自动续作两次，次数跨重启保留；人工补充后可开始新的续作周期，不复用旧请求编号。
- 人工回复后的阶段不再沿用旧的 ready/waiting 报告；会话实际运行时显示工作中。自动续作保留成员、执行会话、文件和原权限，不创建原生子代理，也不代替 GitHub 的外部审批。
- 手动模型配置从 DSH 获取服务商名称与当前默认模型，保留自定义输入。加载列表不修改设置或 DSH 默认模型。
- 来源规则使用来源导航和准入表格，按实际内容容器宽度调整；小容器逐行显示准入项。名单编辑使用整行宽度，保留名单、同步、警告、键盘切换和保存逻辑。
