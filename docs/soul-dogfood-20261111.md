## 1.8.10 界面与弹窗复查

区分问题归属：上节的存储命名、工具 JSON 返回和首载设置属于灵魂插件；Superagent 的本轮改动仅涉及界面与菜单交互，没有改变任务调度或成员权限。

- 保留已选的“宽松”密度，收敛三档间距的增量；任务与工作区搜索框统一为 320px 上限，列表与任务侧栏减少重复留白。窄容器中的搜索框仍可占满一行。
- 团队侧栏在常规窗口缩至 248px，协作节点间距相应收紧，会话获得更多空间；半屏仍有会话 / 团队切换。
- 新建任务限制为 760px 宽、780px 高并服从可用窗口，任务要求输入区减少初始空白。分段密度控件与其余设置控件采用相同的跨行居中规则。
- 真实填写第三成员的长名称、多行中文，关闭并在原位更新后重开，内容保留，未复现闪退。验收成员已移除，没有派单；这不等于覆盖所有输入法组合。
- 真实发现：强度菜单打开时按 Esc，会同时关闭新建任务。原先依赖 React 父级按键拦截，未覆盖宿主浮层的 document 路径。新增回归检查先复现失败；现在仅在自身菜单持有焦点时优先处理 Esc。日常 DSH 中已确认菜单关闭、焦点回到强度框、弹窗和草稿保留。
- 弹窗通过 portal 挂载，曾漏用页面的滚动条隐藏规则；现在本插件弹窗也隐藏滚动条，保留滚动与多行编辑。
