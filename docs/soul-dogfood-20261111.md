# 用 Superagent 开发灵魂插件

本轮从真实「新建任务」表单派单，使用独立目录 `Missher-DSH-Soul`。协调、实施、验证、界面与接入四个成员的实际模型配置均为 `qwen-token-plan / qwen3.7-plus / high`。原生思考强度插件将最高档显示为 Ultra；展开可见实际值 `high`，没有改用其它强度。

## 表单问题

| 实际操作 | 发现 | 修复与检查 |
| --- | --- | --- |
| 编辑较长成员名 | 成员标题由 48px 增到 70px，带动分工输入区移动 | 标题和分工摘要单行省略，保留完整名称提示与原生展开操作；源码预览保持 48px |
| 新建任务中填写路径、标题 | 浅色输入提示接近背景，难以辨认 | 改用宿主次要文字色；预览由 `#e1e5ee` 改为 `#61666b` |
| 选择任务、成员模型与强度 | 使用系统原生下拉，与插件设置菜单不一致 | 复用现有宿主 Menu 选择器，保留模型 ID、继承关系、键盘及表单行为，标准强度本地化 |
| 760×700 窗口查看正在开发的任务 | 协作栏仍占一列，会话只有约 368px 宽，输入工具栏拥挤 | 按插件可用宽度提前切换会话 / 团队单栏，保留两个面板的切换入口 |

第三成员中文输入法合成输入未复现闪退；折叠空白分工后提交，能自动展开、聚焦并说明缺失项。两项保留原实现。长文本多行编辑的首行可见性检查通过，没有据猜测改变文本对齐。

## 开发过程复查

首轮源码中的主动发送日志、风格学习注释和设置页模拟保存不符合任务要求，已通过实施成员的真实内嵌会话追加反馈，要求接通真实宿主接口。构建与单元测试不代表这些能力已经可用。最终状态以插件安装后的真实对话、持久化、后台调用与调度投递为准。

## 1.8.8 实际安装复查

日常 DSH 已原位更新至 1.8.8，插件启用、运行服务就绪，安装包内 46 个文件与实际安装一致。原团队四个会话 ID 均保留。

重新加载真实宿主界面后，长成员名标题保持 48px，输入提示使用 `#61666b`。从新菜单选择 Qwen3.7 Plus 和「高」，实际表单值分别为 `qwen-token-plan / qwen3.7-plus` 与 `high`，焦点返回强度按钮。760×700 窗口出现会话 / 团队切换，页面没有横向溢出；上述检查未注入预览样式。

初始表单相关 56 项检查通过；完整套件 1328 项中三个子进程检查在高负载时失败，单进程重跑相关 28 项全部通过。新增额度状态后，相关状态、团队及界面 58 项检查通过，类型检查与构建通过。没有为消除超时修改产品逻辑或提高全局测试时限。

真实开发中，Qwen 三次返回 429 / QUOTA 后曾恢复。另一次模型生成的读取参数多了逗号，成员正确停止并保留现场；在新版本点击「重试成员」后，同一任务、同一会话重新执行，模型仍是 Qwen3.7 Plus / high。此记录不将模型参数生成错误说成插件已能消除的错误。

灵魂插件仍需完成宿主接入和真实对话验收；1.8.8 仅发布上述 Superagent 修复，不包含未完成的灵魂插件代码。
